# Этап 2: Авторизация — что делать

## 1. Проверить, что включён Email/Password в Firebase Console
Build → Authentication → Sign-in method → Email/Password → Enable.
(Если уже сделали раньше — пропустите.)

## 2. Структура файлов
Скачайте все файлы, сохраняя структуру папок:
```
techstore/
├── index.html
├── login.html
├── register.html
├── profile.html
├── firestore.rules
├── css/
│   └── style.css
└── js/
    ├── firebase-config.js
    └── auth.js
```

## 3. Как проверить локально
HTML-файлы с `type="module"` не откроются просто двойным кликом (браузер
блокирует модули на file://). Нужен локальный сервер. Проще всего:

- Если стоит VS Code — установите расширение **Live Server**, откройте
  папку `techstore`, правый клик на `index.html` → **Open with Live Server**.
- Или через терминал (если есть Python):
  ```
  cd techstore
  python -m http.server 5500
  ```
  и открыть в браузере `http://localhost:5500`

## 4. Что проверить руками
1. Открыть `register.html` → зарегистрировать себя
2. Зайти в Firebase Console → Authentication → Users — должен появиться
   новый пользователь
3. Зайти в Firestore Database → коллекция `users` — должен появиться
   документ с вашим uid, полями name/email/role: "user"
4. Открыть `login.html` → войти этими же данными
5. Проверить `profile.html` — должны подтянуться ваши данные, попробовать
   изменить имя/телефон и сохранить
6. Проверить кнопку «Выйти»
7. Проверить «Восстановить пароль» (придёт письмо на почту)

## 5. Назначить себя админом
После того как зарегистрировались (шаг 4.1), в папке `techstore-seed`
(там же, где `seed.js` и `serviceAccountKey.json`) положите новый файл
`make-admin.js` (я его туда же добавил) и выполните:

```
node make-admin.js ваш@email.com
```

Проверьте в Firestore → users → ваш документ — role должен стать "admin".
После этого перезайдите в profile.html (или обновите страницу) — увидите
роль admin и ссылку «Админ-панель» в меню (сама админ-панель — следующий
этап).

## 6. Применить Security Rules
1. Firebase Console → Build → **Firestore Database** → вкладка **Rules**
2. Откройте файл `firestore.rules`, скопируйте всё содержимое
3. Вставьте в редактор правил в консоли, заменив то, что там было
4. Нажмите **Publish**

⚠️ После публикации правил доступ станет ограниченным по ролям — если
после этого что-то в проекте перестанет работать (например, чтение
каталога), пришлите мне текст ошибки из консоли браузера (F12 → Console).
